# Security reports

Do not post credentials, private recordings or exploitable private details in public issues. Use GitHub's private vulnerability reporting for this repository once enabled. If it is unavailable, request a private reporting channel without publishing the vulnerability details.

Release maintainers must enable private vulnerability reporting before public launch. No support email or response-time guarantee is published until its owner confirms it.

Reports should include the affected version/channel, a minimal fictional reproduction, expected capture scope and the impact. Echo Voice's critical boundaries are local-only inference, explicit source selection, app-managed path validation, durable recording and verified model data.
